# Golang for Mobile Development

## [GOMOBILE](https://go.dev/wiki/Mobile)

GOMOBILE is a tool that allows you to write mobile applications in Go. It provides a way to build and package Go code for Android and iOS platforms, enabling developers to leverage Go's performance and simplicity in mobile app development.

- [Github Repository](https://github.com/golang/mobile)

## [GopherJS](https://github.com/gopherjs/gopherjs)

GopherJS is a compiler that compiles Go code to JavaScript, allowing developers to write web applications in Go. It enables the use of Go's features and libraries in a web environment, making it easier to build complex web applications.

- [Github Repository](https://github.com/gopherjs/gopherjs)
